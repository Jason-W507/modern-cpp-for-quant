\section{第 1 章}
\subsection*{自测答案}
\begin{enumerate}
  \item \texttt{\#include} 在预处理阶段处理，不是以分号结束的 C++ 语句；它让当前翻译单元看见 \texttt{iostream} 中的声明。
  \item \texttt{main} 是程序入口名，空圆括号表示本版本不接收参数，花括号包围函数体；状态 0 表示成功，非零表示失败。
  \item \texttt{std::} 指定标准库命名空间，\texttt{<<} 把右侧文本送入输出流，双引号界定字符串字面量，\texttt{\textbackslash n} 换行，分号结束语句。
  \item 流水线是预处理、编译、链接和运行；\texttt{-c} 在目标文件处停止，因此能证明编译通过，却不能证明链接成功。
  \item 缺分号是编译失败；只有声明没有定义是链接失败；打印启动错误并返回 2 是运行期失败。修复分别恢复语法、加入定义、补齐启动条件。
  \item CMake 用 \texttt{-S} 指源目录、\texttt{-B} 指构建目录。删除旧构建树后从不存在的 \path{build/} 成功配置、构建和运行，才是干净构建证据。
  \item Windows 可执行文件带 \texttt{.exe}，路径分隔和编译器警告选项不同，多配置生成器还包含配置目录；预处理、编译、链接、运行的阶段模型不变。
\end{enumerate}

\section{第 2 章}
\begin{enumerate}
  \item 初始化在对象创建时给出初始状态；赋值修改已存在对象。局部 \texttt{int x;} 没有可靠初值，\texttt{int x\{\};} 值初始化为零。字符字面量用单引号，字符串字面量用双引号；可运行演示见 \path{code/ch02/objects_and_literals.cpp}。完整筛选答案见 \path{code/ch02/market_filter.cpp}，给定五行输入应输出 \texttt{selected=2 rejected=3 buy\_notional=1035.75 average=517.875}。
  \item \texttt{auto} 仍在编译期推导出固定类型；当位宽或领域含义重要时显式写出类型。\texttt{5 / 2} 先做整数除法得到 2，\texttt{5.0 / 2} 得到 2.5；平均值分母可写成 \texttt{static\_cast<double>(selected)}。
  \item \lstinline|a && b| 在 \texttt{a} 为假时不求值 \texttt{b}。\texttt{switch} 漏写 \texttt{break} 会贯穿后续标签；\texttt{default} 接住未识别方向。已知迭代次数用 \texttt{for}，由状态决定终止用 \texttt{while}。
  \item 风险预算题的完整答案见 \path{code/ch02/exercises/risk_budget_solution.cpp}；3200 按每笔 750 扣减四次后剩 200。计数循环的独立答案见 \path{code/ch02/for_scope.cpp}。若循环体不扣减预算，条件永不改变，会形成无限循环。
  \item \path{code/ch02/failures/narrowing.cpp} 应在编译阶段得到“列表初始化拒绝窄化转换”类别。可把接收对象改为 \texttt{double}；若业务确实需要整数，先定义截断、四舍五入或拒绝策略，再显式转换。
\end{enumerate}

\section{第 3 章}
\subsection*{自测答案}
\begin{enumerate}
  \item 声明给出返回类型、名称和参数表并以分号结束；定义给出匹配接口与函数体；调用用实参创建参数对象并取得结果。定义的右花括号后不加函数声明式分号。
  \item 按值或引用参数在调用期间有效，局部对象在离开函数时销毁；返回值交回调用者。早返回在满足条件时立即结束本次调用，跳过后续语句。
  \item 按值允许修改独立参数而不影响调用者；\texttt{const T\&} 只读借用；\texttt{T\&} 可修改调用者；\texttt{const T*} 是可空的只读观察，检查不为 \texttt{nullptr} 后才能解引用。
  \item 重载靠参数数量或类型区分，并要求调用时存在唯一最佳候选。只改变返回类型无法总由实参确定选择，因此不能形成可调用的重载集合。
  \item 每个 \texttt{.cpp} 连同包含的声明形成独立翻译单元并编译为目标文件；链接器把目标文件与库组合为可执行文件。头文件自身不会自动提供实现。
  \item include guard 让同一头文件在一个翻译单元重复包含时只展开一次。项目头文件用双引号配合目标 include 路径；命名空间降低项目名称与其他库冲突的风险。
  \item 缺失定义与重复定义都在各翻译单元编译后由链接器报告；返回局部对象引用可由高警告级别在编译时指出，其后读取是未定义行为，不运行来验收结果。
\end{enumerate}

\section{第 4 章}
\subsection*{自测答案}
\begin{enumerate}
  \item \texttt{string} 保存拥有的字符序列；\texttt{vector<double>} 保存动态数量的同类型连续元素；\texttt{array<string, 3>} 的长度 3 属于类型。三者都不能像 Python list 一样随意混放无关类型。
  \item \texttt{size} 是已存在元素数，\texttt{capacity} 是当前分配可容纳数。\texttt{reserve} 只提高容量下界，\texttt{resize} 改变大小并构造或销毁元素。
  \item 半开区间包含 \texttt{first} 而不包含 \texttt{last}；空区间可由 \texttt{first == last} 表示，因此尾后迭代器只用于比较，不能解引用。
  \item vector 重新分配会使全部旧位置失效；插入或删除还可能使操作点及其后位置失效。可预留足够容量，或修改后重新取得迭代器、引用和指针。
  \item lambda 的 \texttt{[]} 是捕获列表，\texttt{()} 是参数表，\texttt{\{\}} 是函数体；空捕获不读取周围局部对象。\texttt{[minimum]} 按值捕获阈值。
  \item 操作正好是查找、计数、复制、排序、转换或归约时，算法直接表达意图；多状态、早停或逐行诊断常由普通循环更清楚。两者都必须满足范围、输出空间和迭代器有效性前置条件。
  \item 打开失败属于文件边界；列数与数值错误属于带行号的数据边界。三者均返回 2，但诊断分别为 cannot open、expected columns 与 invalid number。
  \item 三个平行 vector 的同一索引共同表示一行，因此长度必须相等。第 5 章用一个行情记录类型把 symbol、price、quantity 组合成单个元素，消除同步修改三列的脆弱约束。
\end{enumerate}

\section{第 5 章}
\subsection*{自测答案}
\begin{enumerate}
  \item \texttt{struct} 默认公开，\texttt{class} 默认私有；两者都能声明访问标签、构造函数和成员函数，共享同一套对象模型。选择应表达“透明记录”还是“维护不变量的抽象”。
  \item 作用域枚举把枚举项保留在类型作用域并阻止静默整数转换，因此写 \texttt{Trend::up}。分支直接 \texttt{return} 或 \texttt{throw} 时不需 \texttt{break}；仍要继续执行函数时，\texttt{break} 防止贯穿下一标签。
  \item 构造函数建立对象，没有单独返回值。成员初始化列表在进入函数体前构造成员；函数体随后检查字段组合，不满足时抛出且对象不交付。
  \item \texttt{price() const} 的尾随 \texttt{const} 约束当前对象不被成员函数修改；\texttt{const std::string\&} 约束调用者通过返回引用只读观察字符串，并要求借用不超过对象寿命。
  \item \texttt{this} 是当前对象的指针；\texttt{this->prices\_} 通过指针访问当前对象成员，\texttt{quote.price()} 用点号从已有对象调用成员。无歧义时成员函数内可省略 \texttt{this->}。
  \item \texttt{MarketQuote} 的空代码、非法价格和非正数量会破坏所有后续统计，适合在构造边界拒绝。\texttt{MarketSummary} 是已经计算完成、无需继续维护跨字段状态的透明结果，适合公开字段。
  \item 异常传播会按逆序销毁已完成构造的自动对象；未完成构造的目标对象不存在。CLI 有能力决定 stderr 与退出码，因此在那里记录一次，内层只补充字段和行号上下文。
  \item 读取 \texttt{quantity\_} 违反访问控制，在编译期得到 private/inaccessible 类别；负价格语法有效但违反领域不变量，在运行期抛出并转成状态 2。恢复分别是调用公开观察函数、修正输入或在构造边界拒绝。
\end{enumerate}

\section{第 6 章}
\subsection*{自测答案}
\begin{enumerate}
  \item 构造成功后对象生命周期开始，析构完成后结束；存储中的旧比特不会让已析构对象重新存在。自动对象按逆构造顺序销毁。
  \item \texttt{std::move} 只把表达式转换为可选择移动操作的值类别。移动后的源对象仍可析构、可赋值，但除非类型契约另有保证，不能假定保留原值。
  \item 引用和裸指针通常只借用；\texttt{unique\_ptr} 是可转移的唯一所有者；\texttt{shared\_ptr} 让多个参与者共同决定寿命。直接值仍是最简单的默认所有权。
  \item C 数组退化为指针后不再携带长度。\texttt{new[]} 建立的数组必须由 \texttt{delete[]} 释放；与标量释放形式混用是未定义行为。
  \item RAII 让栈展开和所有提前离开路径都触发析构；Rule of Zero 把释放交给可靠成员，避免外层类型手写一组容易不一致的复制、移动和析构操作。
  \item \texttt{weak\_ptr} 不增加强计数，因此可打破共享环；\texttt{shared\_ptr} 只协调控制块寿命，不会自动同步被管理对象的字段。
  \item ASan 报告同时给出分配、释放和非法访问位置。按这三处重建生命周期图，再恢复单一明确的所有者和不越界的借用期。
\end{enumerate}

\noindent\textbf{完整核心证据：}生命周期、RAII、所有权选择和 ASan 失败分别由上述真实源码与 expected/诊断类别验收。\textbf{异步整合题的分层反馈：}提示是先让任务按值保存可复制订单；不可复制时再按值接收并移动捕获 \texttt{unique\_ptr}。验收要求提交函数已经返回后任务仍能得到原订单值，所有权转移后调用者指针为空，且不引入无需求支持的共享寿命。常见错误是按引用捕获栈上订单，或用 \texttt{shared\_ptr} 掩盖谁应拥有任务数据。

\section{第 7 章}
\begin{enumerate}
  \item 成交时间线按到达顺序追加和扫描，\texttt{vector} 的连续拥有存储适合批处理；仓位按代码查询，\texttt{map} 把键查找写进接口。若改用其他容器，必须给出访问与失效依据。
  \item \texttt{positions[key]} 会在缺失时插入值初始化的整数，适合累计；\texttt{positions.at(key)} 只查询，缺失时抛出异常。范围循环按键顺序遍历 \texttt{map}，本例得到 AAPL、MSFT。
  \item 排序会改变顺序，因此复制后排序价格；\texttt{find\_if} 必须观察原时间线，才能回答“首笔卖出”而不是“排序后第一笔卖出”。
  \item view 创建后才把 99 改成 110，最终仍输出 220，证明筛选与转换在迭代时求值。view 按值拥有 adaptor 状态，却借用 \texttt{prices} 的元素与存储。
  \item 返回 view 时局部 \texttt{vector} 已析构，view 内的引用悬空。可让源容器由调用者拥有、在原作用域消费，或在返回前复制到拥有元素的容器。
  \item \texttt{back\_inserter} 把赋值转换为 \texttt{push\_back}，使 \texttt{ranges::copy} 能向初始为空的 \texttt{vector} 追加结果，而不要求预先创建可写元素。
  \item 初值决定累加器类型。\texttt{0.0} 让名义金额按 \texttt{double} 累加；写 0 会让累加器成为 \texttt{int}，每一步都可能截断小数。
  \item 浮点加法不满足数学上的结合律，舍入发生在每一步。本章只承诺固定程序与输入下的测试结果，不承诺任意重排逐位相同；稳定求和与容差来源见第 16 章。
\end{enumerate}

\noindent\textbf{完整实现：}核心编码任务位于 \path{code/ch07/exercises/top_prices_solution.cpp}。它先把惰性筛选结果物化，再排序拥有元素的副本，最后用 \texttt{take(2)} 限制输出；运行 \texttt{ch07\_top\_prices\_solution} 应精确输出 \texttt{top=AAPL@102.00,AAPL@101.00}。

\textbf{分层反馈：}提示是先决定结果由谁拥有，再组合 range；验收是项目答案从 \path{code/ch07/CMakeLists.txt} 独立构建且精确输出通过；常见错误是返回借用局部容器的 view，或对未物化结果排序。非法生命周期实验只验收 ASan 的非零退出与稳定类别。

\section{第 8 章}
\begin{enumerate}
  \item 接口应从“低价空仓下单、代码一致且流动性足够才成交、组合应用成交”等用例产生；没有用例支持任意改价，因此不提供 setter。
  \item Order 拥有自己的 string 和数量，复制得到独立对象；\texttt{const Order\&} 只借用调用者对象，不复制也不延长其生命。
  \item 数量必须为正；行情和成交价格还必须为正且有限，因为 NaN 与零比较可能绕过仅有的大小检查。
  \item 不下单是正常缺席，使用空 optional；数量为零是非法订单，不能让一个哨兵对象同时表达两种语义。
  \item 代码不匹配或流动性不足是本次无法撮合，返回空 optional；构造非法 Fill 则违反领域前置条件。
  \item apply 在写现金和仓位前完成超卖与现金检查；测试比较拒绝前后公开 snapshot，而不读取私有 map。
  \item 默认用值成员和组合；只有启动后必须通过同一接口选择实现时使用虚函数；编译期泛型留到第 9 章。

\section{第 15 章}
\begin{enumerate}
  \item data race 是未由 happens-before 排序的冲突访问，且至少一个是写；它属于 UB。一般竞态只表示结果依赖合法调度顺序，不必然含有未同步内存冲突。
  \item 工作线程完成同步于成功返回的 join，因此线程内写入 happens-before 之后读取；引用捕获还要求被借用对象至少活到 join 完成。
  \item atomic 只使各自对象的操作原子化；读取 cash 后、读取 position 前，另一个线程仍可完成一半更新，所以二者不组成同一快照。

  \item 阻塞、拒绝/重试、丢新、丢旧、合并或溢写都可能合理；依据是数据可丢性、顺序、延迟、内存预算和恢复成本。
  \item request\_stop 发出协作取消请求，close 宣布不再生产并允许排空，join 等待线程结束并建立完成同步；三者不能互相替代。
  \item 未捕获异常逃出线程入口会 terminate；async 把异常存进共享状态，future::get 在调用方重新抛出。
  \item 8 行样本只验证结果。性能报告还需 Release 环境、真实工作量、线程数、启动口径、原始样本以及队列阻塞、满和丢弃指标。

\section{第 16 章}
\begin{enumerate}

\section{第 18 章}
\begin{enumerate}

  \item 原输入让别人复现，根因区分症状与真实缺失契约，回归证明最小修复没有只隐藏当前错误。只有“修了一个 bug”不能判断问题、贡献或复发风险。
  \item “生产级、高频、实盘、低延迟、盈利、支持多资产”均超出当前证据。可改为“单代码同步教学回测；有费用/滑点、四个 seam、显式估值拒绝和正确性门控 benchmark”，并列出下一步契约。
  \item 个人项目能回答自主学习、技术判断和失败修复，不能凭空产生团队冲突。应明确项目性质，再用真实课程、实习、工作或开源评审回答协作；没有合适经历时诚实说明，不虚构角色与影响。
  \item 小改动限制失败半径，容易建立独立 oracle、评审、回滚和上线观察，也让新人先验证自己理解的业务契约。大重写会同时改变过多假设，难以区分学习偏差与真实改进。
\end{enumerate}
