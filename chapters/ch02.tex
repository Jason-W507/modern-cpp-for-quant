\section{类型决定表示与合法操作}

在 \python{} 中，变量名引用对象，名称本身没有固定类型；在 \cpp{} 中，对象的类型决定大小、对齐、生命周期和候选操作。量化代码若把价格、数量、时间戳和方向都表示成无语义的 \texttt{double} 或 \texttt{int}，编译器无法阻止参数错位。

最小改进是使用作用域枚举和领域结构体：

\begin{lstlisting}
enum class Side : std::uint8_t { buy, sell };
struct OrderIntent {
  std::string symbol;
  Side side;
  std::int64_t quantity;
};
\end{lstlisting}

\texttt{enum class} 不会隐式转换为整数，也不会把 \texttt{buy} 泄漏到外围命名空间。对于货币，教程示例会明确说明使用二进制浮点是为了聚焦语言机制；生产系统需要根据资产最小报价单位、舍入规则和跨币种计算选择整数 ticks、定点数或经过验证的十进制类型。

\section{初始化优先于赋值}

对象生命周期从初始化开始。优先使用花括号初始化，因为它禁止部分窄化转换：

\begin{lstlisting}
int quantity{100};
// int broken{100.5}; // compile error: narrowing
double price{188.5};
\end{lstlisting}

默认初始化基础类型可能留下不确定值，读取它会导致错误甚至 UB。聚合类型用成员默认值建立可预测状态，但“全为零”不一定是业务上合法的订单；应在构造边界验证正数量、有限价格和非空代码。

\section{表达式也有值类别}

对象有类型和生命周期，表达式还具有值类别。够用的工作模型是：左值通常具有稳定身份，可以取地址；纯右值通常代表待物化的计算结果；将亡值允许资源被移动。\texttt{std::move} 不移动任何东西，它只是把表达式转换为允许移动构造/赋值的值类别。

\begin{pythonbridge}
\python{} 赋值通常复制引用；\cpp{} 的按值赋值通常复制或移动对象本身。\texttt{auto b = a;} 对 \texttt{std::vector} 意味着独立容器复制，而不是让两个名称自然共享同一列表。
\end{pythonbridge}

\section{const 的边界}

成员函数末尾的 \texttt{const} 表示不通过该接口修改对象的逻辑状态，并允许在常量对象上调用。它不是线程安全承诺。多个线程同时访问对象时，只要至少一个写入且缺少同步，就可能形成数据竞争。

顶层 \texttt{const} 修饰对象本身；底层 \texttt{const} 修饰指向或引用的对象。阅读复杂声明时先找到变量名，再由内向外读取。更重要的是减少复杂声明：用类型别名、范围和小接口表达意图。

\section{生命周期与悬空}

返回局部变量的引用、把临时字符串转成长期保存的 \texttt{string\_view}、在容器扩容后继续使用旧迭代器，都会产生悬空。编译器无法识别所有此类错误。

安全默认值是：跨作用域保存数据时拥有它；只在短而清晰的调用链中借用它；容器变更前查阅迭代器失效规则。所有权不清时，先画出“谁创建、谁销毁、借用持续多久”。
